## Environment notes and follow-ups

- **renv is empty in this worktree**, so `quarto check` reports "The knitr package is not
  available" and any render inside the worktree fails at the first non-base package.
  All renders were therefore run in `.ebk-ir3-tmp/book2`, a copy without `.Rprofile` and
  `renv/`, using the globally installed R 4.6.1 library. CI (setup-r-dependencies) is the
  authoritative build.
- **Error layout may differ in CI.** `evaluate` 1.0.5 prints errors as `Error:` plus
  `! message`; older versions print `Error in call : message` on one line. The prose only
  quotes the message text, so it stays correct either way, and the chunk output is
  regenerated on each build.
- **Course links** use the single `course1_url` variable (`https://app.rsquaredacademy.com/`),
  so "lesson 1" and "lesson 5" are labels, not deep links, exactly like the existing
  chapters. If per-lesson URLs appear later, only the footers change.
